# Calculadora Básica
## Descrição
Dá os resultados de expressões básicas com as quatro operações fundamentais na ordem que aparecem com pressisão de 15 casas decimais.

## Instalação
É necessário ter c++.

## Exemplo
Para fazer a operação de soma se usa +, subtração se usa -, divisão se usa /, multiplicação se usa *.
### Exemplo de entrada:
1+1*2/4=
### Saída:
sua resposta é 1
